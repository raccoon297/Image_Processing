# 🔫 Hand Gun Fruit Shooter

손으로 총 모양을 만들어 떨어지는 과일을 맞히는 게임!

## 설치 방법

```bash
pip install opencv-python mediapipe pygame numpy
```

## 실행 방법

```bash
python fruit_shooter.py
```

## 조작법

| 동작 | 효과 |
|------|------|
| 검지 펴고 나머지 접기 | 총 모양 인식 (조준선 표시) |
| 검지를 구부리기 | 발사! |
| SPACE | 게임 시작 |
| R | 다시 시작 |
| ESC | 종료 |
